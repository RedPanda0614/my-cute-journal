# 开源素材 · 来源和许可

一共 10 套,都可以免费用,包括商用。工作台素材栏「素材套」那一行,一套一个标签。

- 「公有领域」:原书出版很早,版权已经过期。图片来自古登堡计划(Project Gutenberg)在 GitHub 上的镜像 GITenberg 等。
- 「CC0 1.0」:作者放弃了全部权利。
- 处理:彩图去掉了纸色底,黑白木刻和版画换成深棕墨色、透明底;墙纸保持原样。

- 出处:WelshPixie/vintageart:19 世纪末到 20 世纪初公有领域印刷品的描摹
- 许可:CC0 1.0
