## 验证

`catalog.json` 和 `catalog.js` 保存每份字体原始文件的 SHA-256 与真实 cmap 覆盖范围。运行 `scripts/verify_font_catalog.py`（需要 fonttools）可独立核对原始文件、字族名称、许可证及预览字符。

`render-audit.json` 保存浏览器相同字号、相同语言示例下的像素 SHA-256：30 份渲染均不同。此结果证明这些样例未落到相同的替代字形，不等于所有字形在任意字号下都容易用肉眼区分。

工作台在渲染前检查实际字符覆盖并等待字体加载完成。缺字、字库文件加载失败时阻止应用，不以系统字体或文楷冒充所选字体。正文和小标题分别选择字族；英文字体示例使用 Monday。
