# 手帐工作台 · my cute journal

一个手工风的电子手帐工作台。像在真的桌面上做手帐：选纸、贴胶带、剪贴纸、写字，最后导出成图片或打印用的 PDF。

全部在浏览器里运行，不需要安装。页面与本地开源字库放在 `网页源码/` 中。

## 怎么用

推荐双击根目录的 `启动工作台.command`，用 Chrome 打开本地工作台（需要 Python 3）。人物提取需要这个本地服务；其他编辑功能也可直接打开 `网页源码/index.html`。

- 用 `启动工作台.command` 打开时，作品每次改动后自动存到根目录 `作品/自动保存.json`，每天另存一份到 `作品/备份/`（保留 30 天）；右上角显示保存状态。
- 直接双击 `index.html` 打开时，作品只存在浏览器里；超过一天没备份会提醒「下载备份」，以后从「作品 ▾ → 从备份文件打开」接着改。
- 30 款开源字体随项目保存在 `网页源码/fonts/`，无需在线字体服务。复制页面时保留整个 `网页源码/` 文件夹。
- 手抖、仿书法这些字效靠 Chrome 的 canvas 滤镜，Safari 可能显示成普通字。

## 有什么

- **纸**：A5 / A6 / B6 / TN / 护照本 / 方形 / 小红书 3:4 / 自定义，横竖、单页跨页；米白、牛皮、方格、点阵、横线、盐系、描图纸。
- **素材**：自带胶带、纸片、小涂鸦（代码现画）；上传自己的图；整张素材页自动拆成小素材；十个固定用途分类（含照片）、独立标签库、自建收纳夹、收藏、按颜色找。
- **编辑**：移除画布浮动属性条，统一到左侧主题分组：变换与图层、文字、抠图、裁切与拆分、贴纸效果、相框与纹理、调色、涂鸦。裁切下拉选择矩形裁切、不规则裁切、素材页拆分；不规则裁切支持自动识别背景轮廓、手绘保留区域、点选清除内部背景；自动去背景支持清理同色中空区域，可关闭以保留同色细节。
- **文字**：基础字体、字效、剪报字体与 13 种带小装饰的手帐标题（来自 `字体skill原型/`）；字效和 30 种真实字体均有预览，基础示例为「星期一」，标题示例为「星期一 / 天气晴」，文字也能剪裁。
- **图层**：拖动排序，多选分组；支持组名、收起、整组排序、显示/隐藏、锁定/解锁和解散分组，随项目保存；支持选中图层合并为透明图片、删除所选和清空本页未锁定图层，均可撤销。
- **剪报字体**：在文字栏内逐字/逐词生成，独立纸底与真实字体，支持预览、单字编辑、重新打乱、整组移动/缩放/旋转。旧版剪报拼字入口已统一，不影响已有作品。
- **人物提取**：上传照片并添加到画布后，在左侧「编辑 → 抠图」点「提取人物」，预览透明效果，调整保留范围和边缘柔和后应用。模型随工作台本地保存，照片不上传；复杂背景和细发丝可能需要不规则裁切修整。
- **涂鸦**：编辑栏的细笔和半透明荧光笔，每笔成为独立图层。
- **照片**：黑白、复古、网点、颗粒；拍立得/邮票/胶片/圆形相框，支持放大和移动照片内容。效果保留源图，替换照片保留位置、大小和相框。
- **风格**：盐系、复古、美式杂志、手绘旅行四套纸材与可编辑样页，每套12种纸材和装饰。
- **作品库**：保存或另存完整项目和1080×1440 成品图，支持打开、改名、删除、下载项目和成品图。
- **多页**：一个项目放一整本，每页纸种可以不同。
- **导出**：PNG（300dpi / 屏幕）、小红书 1080×1440、PDF（3mm 出血 + 裁切线）；可以整本导出。

文字按基础字体、字效、手帐标题、剪报字体分类。字体支持名称/风格搜索、中文/英文及手写体/打印体/艺术体筛选；选中已有文字时可用当前文字比较字形。缺字或加载失败会明确提示，不再默默回退为另一字体。正文与小标题可分别选择字体。点预览卡片打开输入框，双击纸上的文字可编辑。

素材栏宽度可拖动，素材和文字卡片尺寸固定，宽度变化只调整列数与间距。点击纸面素材或文字会打开左侧编辑；拖动素材保持当前侧栏，画布不再叠放属性条。

素材按胶带、贴纸、照片、便签和纸片、打底纸/背景纸、票据和收集物、印章和火漆、文字和标题、手绘和小装饰、实物质感十类归档；另设待分类。盐系/复古/美式杂志/手绘旅行改为独立风格筛选，剪报字体归入「文字」，画笔归入「编辑 → 涂鸦」；不再有单独的拼贴页。左侧「风格」「作品」分别管理样页和作品库。选中图片后，在「编辑 → 相框与纹理」设置效果或替换照片；样页照片位使用示例插画，双击可换成自己的照片。作品库存于当前浏览器，可下载项目文件备份。四套样页的导出图和可编辑项目见 `versions/v19/samples/`。

拖动纸面空白处框选完整素材；画面被素材覆盖时，可点画布底部或编辑栏的「框选」后再拖。Shift 可追加，锁定和隐藏项不参与框选。用「删除所选」或 Delete/Backspace 删除，撤销可恢复。

调色提供曝光（EV）、对比度、高光、阴影、色温、色调、饱和度，先预览，点击「应用」才写入项目和撤销记录；取消丢弃预览，归零将参数恢复为中性。保留调色源图和参数，重复调整不叠加损失。分组参考 [Lightroom 光线与颜色基础调整](https://helpx.adobe.com/lightroom/desktop/edit-photos/edit-photos.html)，工作台针对普通位图实现基础调整，不含 RAW 工作流。

素材收纳栏固定两行：分类下拉与收藏，下面是风格、来源、标签、收纳夹。分类列表和标签库临时展开，不增加常驻高度。标签支持搜索、多标签交集筛选、新建、改名和移除；胶带的常用标签按材质、宽度、工艺组织，标签建议不表示已内置对应实物材质的图片。来源分内置素材、我的上传、工具生成。

自建收纳夹可跨类别收集，同一素材可放入多个夹子；在详情卡或素材多选栏中设置。删除夹子只解除归属。旧的自建分类自动转为收纳夹，旧风格分类转为风格属性，原素材和画布不丢失。分类、风格、标签和收纳关系随项目保存，玩家自建标签保存在独立标签库中。拖动素材停在分类/收纳夹入口上可展开并放入目标，拖到收藏按钮可收藏。

上传时选择「素材纸 / 照片」。素材纸默认待分类，每个文件按文件名建立独立收纳夹，整张保存或拆出的所有小素材保留同页来源；之后手动改为贴纸、胶带等用途，不改变来源收纳。多文件逐张处理和「剩余全部整张保存」都按各自文件收纳，不继承上一张的用途分类；同名收纳名自动加序号。取消上传不创建空夹子。收纳夹菜单将素材纸、相册、自建收纳夹分段显示。

选择「照片」后默认进入照片类，可选填写相册名；不填时不逐张建立相册。在照片分类发起上传会默认照片类型。图片后续从编辑栏拆分时，拆出的小素材继续沿用原素材纸收纳，分类默认为待分类。原先已归类的素材保持既有用途，可通过多选批量重新归类。

## 文件夹

| 路径 | 是什么 |
|---|---|
| `网页源码/index.html` | 工作台入口（最新版） |
| `网页源码/workbench-extras.js`、`workbench-extras.css` | 纸材、剪报字体、照片、风格样页与作品库扩展，须与入口一起保留 |
| `网页源码/material-library.js` | 固定素材分类、风格/来源/标签筛选、多收纳夹与旧数据迁移 |
| `网页源码/workbench-editor.js` | 左侧主题编辑、纸面框选和保留源图的基础调色 |
| `网页源码/workbench-tools.js`、`person-worker.js` | 图层合并/批量删除与本地人物提取 |
| `网页源码/vendor/mediapipe/` | 人物分割运行库、模型、许可证和来源 |
| `启动工作台.command`、`scripts/start_workbench.py` | 本地服务启动入口 |
| `网页源码/fonts/` | 30 款原始开源字库、许可证、来源和字形审计 |
| `scripts/verify_font_catalog.py` | 字库文件、许可证、cmap 与家族名称验证 |
| `versions/` | 每一版的源码、截图和改动记录，`log.md` 是总表 |
| `字体skill原型/` | 手帐标题字的 Python 原型（Playwright 渲染） |
| `功能草稿.md` | 功能规划 |
| `skill清单.md` | 可以用的开源手帐 skill 和授权 |
| `内容卡.md` | 小红书发布用的内容卡 |
