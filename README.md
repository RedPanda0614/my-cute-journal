# 手帐工作台 · my cute journal

本地运行的电子手帐工作台：贴胶带、剪素材、写字、整理图层，导出图片或打印 PDF。当前版本 **v35**，改动与验收见 [v35 验收报告](versions/v35/验收报告.md)。

改代码前先读 [开发规则](开发规则.md)。后续方向见 [改进计划](改进计划.md)。

## 打开与保存

从旧版本升级后，请先关闭旧的本地服务窗口，再重新双击 `启动工作台.command`；页面会识别旧服务并提示重启。

推荐双击 `启动工作台.command`（需要 Python 3），在 Chrome 中使用。也能直接双击 `网页源码/index.html`，包括本地主体提取。

- 本地服务模式：浏览器与磁盘分别保存。每本作品有稳定编号，对应 `作品/项目/` 中独立 JSON；`作品/历史/` 为每本保留最近 40 个不同版本。`作品/自动保存.json` 保留兼容入口，升级前的旧自动保存会先迁移。
- 点击顶部保存状态，或进入「作品 → 磁盘作品与历史恢复」，可查看时间点、恢复整本作品，或把磁盘作品恢复到浏览器作品库。恢复前会保留当前作品；批量恢复保留较新的浏览器作品。
- 顶部区分浏览器待保存/已存/失败，以及磁盘待落盘/正在保存/已存/失败待重试。服务恢复后自动重试，也可以手动重试。
- 双击 HTML 模式只保存到当前浏览器。用「导出 → 作品文件」下载可编辑 JSON；从备份打开可继续创作。备份包含个人元素库和编辑源图。
- `作品/` 是个人数据，不进 Git 仓库。复制工作台时保留整个 `网页源码/` 目录；迁移作品时一并复制作品目录或下载备份。

## 主要操作

**素材**：按胶带、贴纸、照片、便签和纸片、背景纸、票据、印章火漆、文字标题、小装饰、实物质感归类，另有待分类。用途标签和来源素材套分开。上传素材纸按文件名归套，不猜成胶带；照片进入照片分类，可选相册。

素材栏保留「标签 / 素材套」两组胶囊，默认各两行，点「展开 ▾」看全部。末尾「＋ 新建」建立个人标签或素材套；拖素材到标签/套上添加，双击自建胶囊改名或删除。最近、搜索、收藏、颜色、来源和标签遵守相同筛选条件。

自带 10 套、471 个公有领域或 CC0 开源素材，用到时载入大图；来源和许可见 `网页源码/素材库/开源/来源和许可.md`。43 个蝴蝶与花框素材补有颜色、形态、构图描述；可以搜索「蓝色蝴蝶」「圆形花框」。原名、编号、来源和用户自定义名称保留。「素材对比」可挑最多四张并排放大查看。

**编辑**：点击纸面内容进入左侧编辑。相框、调色、白边和撕边使用统一源图及可逆参数，改完松手应用，可撤销。调色有曝光、对比度、高光、阴影、色温、色调、饱和度。恢复原图位于底部。矩形裁切、不规则裁切、素材纸拆分放在同一个裁切主题下；主体提取在浏览器本地运行，照片不上传。

**个人元素**：选中一项或一组，在编辑栏点「存为我的元素」。从素材栏「我的元素」搜索并插入。文字、日期卡、分组、相框、源图和相对位置保持可编辑，插入的副本互不影响；可改名、删除，随备份保存。

**照片框**：双击相框从文件换照片，一次只开一个选择器。选中框后「从素材库填照片」，点击已上传照片填入；也可直接把照片拖到相框上。外框位置、尺寸、旋转保持不变。「框内构图」可拖动内部照片并完成/取消，放大仍可用滑块。普通图片双击不会打开换图选择器，文字双击编辑文字。

**图层与多选**：空白处拖动框选，或点底部「框选」后拖；框选完成一次自动退出。Shift 点选追加，图层栏勾选也能多选。多选显示共同透明度及整体平移/旋转，可直接拖动选区，保持相对布局；锁定项跳过。组有「选择整组 / 进入组内」入口。图层可拖动排序、分组、合并、删除所选或清空本页，均支持撤销。

**制作胶带**：在原图选取图案片段，选择重复或拉伸，再分别设置长度与实际宽度（mm）、透明度、底色和两头形状。取图范围只改变构图，不代替胶带物理宽度。

**文字与卡片**：30 款本地开源字体及字效均有预览，可按中英文、手写/打印/艺术类别筛选。默认「星期一」，标题小字「天气晴」。输入在弹出的文本框中完成；支持字号、字距、行距、对齐和固定框宽。另有日期、星期、天气、心情卡及剪报字体。

**页面与导出**：纸张尺寸按 mm 显示，支持横竖、单页/跨页及多种纸色纹理；纸种选「自定义照片…」可上传照片当背景，尺寸自动按照片比例改成自定义；已有日记、旅行、月历、照片拼贴模板。导出先看干净的成品预览，可按整本页码查看。PNG 支持 1080×1440、屏幕尺寸或按纸张 300dpi；比例不同时可选留白或居中裁切。打印 PDF 为 300dpi、3mm 出血及裁切线。整本 PNG 按页码打包为 ZIP。JSON 是可编辑备份，PNG/PDF 为成品。

素材与卡片添加后留在当前栏；文字添加后进入编辑。侧栏宽度变化只改变固定大小卡片的排列与间隔。

**生图**：10 张推荐 skill 卡片（城市地标贴纸、水彩贴纸、月历明信片、极简 zine 海报等，都是 MIT 开源），点开有示例大图和可直接复制给自己 AI 的 prompt；做好的图用「导入图片」放回素材栏。

## 开发文件

| 文件 | 职责 |
|---|---|
| `网页源码/index.html` | 入口、画布、文本、项目和基础导出 |
| `网页源码/ui-kit.js` / `ui-rules.css` | 统一组件与最终样式规则 |
| `网页源码/workbench-editing.js` | 可逆图片配方、异步提交、多选变换 |
| `网页源码/workbench-library.js` / `material-descriptions.js` | 有界收纳、候选对比、可编辑个人元素、视觉描述 |
| `网页源码/workbench-photos.js` | 照片入框、拖动构图 |
| `网页源码/workbench-export.js` | 成品预览及相同渲染路径的 PNG/ZIP/PDF |
| `网页源码/workbench-storage.js` | 浏览器事务状态、磁盘队列、重试和恢复 |
| `网页源码/material-library.js` | 分类、筛选、素材套和旧数据迁移 |
| `网页源码/workbench-extras.js` / `workbench-tools.js` | 卡片、风格、图库、合并/删除和主体提取 |
| `网页源码/vendor/u2net/` | 本地运行库、模型和许可 |
| `scripts/start_workbench.py` | 本机服务、多作品文件和历史版本 |
| `scripts/verify_v35_browser.js` / `verify_v35_storage.py` | 隔离浏览器场景及临时目录服务回归 |
| `versions/` | 每版改动源码、原始请求、结果、截图和验收报告 |

服务测试可使用 `--works-dir /tmp/测试目录 --port 8771 --no-browser`，避免写入正式作品。浏览器脚本只在独立测试上下文执行，不在用户的工作页面运行。
