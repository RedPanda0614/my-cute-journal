# 手帐工作台 · my cute journal

一个手工风的电子手帐工作台。像在真的桌面上做手帐：选纸、贴胶带、剪贴纸、写字，最后导出成图片或打印用的 PDF。

全部在浏览器里跑，单个 HTML 文件，不需要装东西。

## 怎么用

用 Chrome 打开 `网页源码/index.html` 就行。

- 作品自动存在浏览器里，也可以点「存工程」下载工程文件，以后「打开」接着改。
- 字体从网上加载，第一次打开要等一下。
- 手抖、仿书法这些字效靠 Chrome 的 canvas 滤镜，Safari 可能显示成普通字。

## 有什么

- **纸**：A5 / A6 / B6 / TN / 护照本 / 方形 / 小红书 3:4 / 自定义，横竖、单页跨页；米白、牛皮、方格、点阵、横线、盐系、描图纸。
- **素材**：自带胶带、纸片、小涂鸦（代码现画）；上传自己的图；整张素材页自动拆成小素材；自建分类、标签、收藏、按颜色找。
- **整理图片**：自动去背景、魔棒、剪裁、白边贴纸、撕边、胶带化、轻调色。
- **艺术字**：24 种，含 13 种带小装饰的手帐标题（来自 `字体skill原型/`），文字也能剪裁。
- **多页**：一个工程放一整本，每页纸种可以不同。
- **导出**：PNG（300dpi / 屏幕）、小红书 1080×1440、PDF（3mm 出血 + 裁切线）；可以整本导出。

## 文件夹

| 路径 | 是什么 |
|---|---|
| `网页源码/index.html` | 工作台本体（最新版） |
| `versions/` | 每一版的源码、截图和改动记录，`log.md` 是总表 |
| `字体skill原型/` | 手帐标题字的 Python 原型（Playwright 渲染） |
| `功能草稿.md` | 功能规划 |
| `skill清单.md` | 可以用的开源手帐 skill 和授权 |
| `内容卡.md` | 小红书发布用的内容卡 |
