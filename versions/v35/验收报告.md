## 实现与边界

新模块按职责拆为 editing / library / photos / export / storage，视觉描述独立维护，最终公共样式在 `ui-rules.css`。版本缓存统一为 `?v=35`。没有增加在线服务或上传照片的依赖。

旧版单一自动保存、已有命名作品库和个人浏览器备份仍兼容。已被旧版覆盖且没有任何源图/历史记录的像素，无法凭空重建。**升级后需关闭旧服务窗口，重新双击 `启动工作台.command`；前端发现旧版服务会提示重启，并停止向旧接口写入。** 直接打开 HTML 仍只能自动存浏览器，磁盘自动保存和历史恢复需启动本地服务。历史按每本最近 40 个不同保存点保留，不是永久无限历史。

PDF 是按 300dpi 栅格化的打印成品；文字和图层的继续编辑使用 JSON。此轮在当前 Chromium 环境实测，不代表 Safari、所有操作系统或高负载大作品的全平台认证。

P2 的个人配色/文字样式、连续日期模板、四风格成品示范、进阶画布导航和输出保持待办。
